# EmulationStation

Esta 'Estación de emulación' no es más que un programa que proporciona una interfaz gráfica para el software de la arcade.

## Guía de configuración

- Se ocultan todas las entradas de Retropie para que no aparezcan al activar el modo kiosk.

- Los juegos arcade (emuladores Mame o FinalBurn) son detectados si se añaden a `roms/arcade`.

 - Para modificar la información sobre un juego pulsar `Select` y entrar en la sección `Edit This Game's Metadata`
